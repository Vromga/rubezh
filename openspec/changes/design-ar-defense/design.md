# Design: «Последний Рубеж»

## 1. Концепция в одной фразе

Ты — оператор оборонной турели «Страж» посреди обычной комнаты. Камера показывает комнату как есть; в стенах, потолке и полу открываются порталы, оттуда лезут роботы Хора. Они хотят утащить «груз» на полу. Не дай им — и не дай разбить твоё стекло.

## 2. Стек и архитектура (решение, обновлено)

Игра для себя и друзей, **только Android** (эталон — Xiaomi 14). Unity отвергнут: на текущей машине (2 ядра, 3,7 ГБ, без GPU) редактор не работает, а для одного Android веб с WebXR достаточен.

| Вопрос | Решение | Почему |
|---|---|---|
| Платформа | Web (PWA), Chrome на Android | Ссылка вместо магазина; APK по желанию через Bubblewrap/Capacitor |
| AR | WebXR `immersive-ar` + `hit-test` (ARCore) | Пол и стабильное 6DoF-отслеживание без ручной калибровки |
| Интерфейс в AR | WebXR **DOM Overlay** | HUD, меню и трещины остаются HTML/canvas |
| Язык | TypeScript, Vite | Типы для данных врагов/оружия, быстрый цикл |
| Рендер | three.js | Ломающиеся части, процедурные эффекты |
| Запасной режим | `DeviceOrientation` + `getUserMedia` | Если WebXR недоступен: 3DoF, пол вручную |
| Звук | Web Audio, пространственный | Слышно, с какой стороны портал |
| Трещины | Canvas 2D/шейдер | Без ассетов |
| Тесты | Vitest для ядра, без рендера | Ядро отделено от three.js |
| Сохранения | `localStorage`/IndexedDB | Без аккаунтов |
| Распространение | HTTPS-хостинг (GitHub Pages и т.п.), «Добавить на главный экран» | Бесплатно |

Слои: `core/` (логика), `render/` (three.js), `xr/` (сессия, hit-test), `input/`, `ui/`, `data/` (JSON баланса).

Риски: нужен «Google Play Services for AR» (Chrome предложит поставить); поддержка DOM Overlay проверяется на реальном телефоне; нагрев — ≤25 врагов; окклюзия мебелью не планируется.

## 3. Сюжет

**2187.** Земля не завоёвана — её *инвентаризируют*. Машинная цивилизация **Хор** собирает всё ценное: людей-колонистов (в консервации — маленькие капсулы-«фигурки»), энергокристаллы, батареи. Хор открывает **Разломы** — порталы в обычных помещениях.

Ты — **Оператор-7**, последний в программе «Рубеж». Твой «Страж» — переносная огневая точка: она не двигается, но видит всё вокруг. Твоя связь — ИИ **«Мара»** (сухой юмор, подсказки в бою).

Акты (сектора):
1. **Гостиная — «Первый Разлом».** Обучение. Мелкие разведчики Хора. Мара знакомит с системой.
2. **Кухня — «Сбор урожая».** Хор крадёт кристаллы и колонистов. Появляются хваталки и щитоносцы. Выясняется: роботы не уничтожают, а *собирают*.
3. **Спальня — «Тишина».** Ночной сектор, невидимки и глушители. Мара признаётся: она — бывший ИИ Хора, перебежчик.
4. **Подвал — «Глубокий Разлом».** Тяжёлая техника. Босс «Жнец» — корабль-тягач, пробивший потолок.
5. **Орбита — «Ядро».** Портал ведёт на корабль Хора. Финальный босс «Хор-Ядро». Концовка: закрыть Разломы или забрать технологию (две вариации финальных реплик, без влияния на геймплей).

## 4. Экраны и переходы

```
Запуск → Заставка → Разрешения → Главное меню ─┬→ Кампания → Брифинг → Калибровка → БОЙ → Итоги ─┐
                                                ├→ Арсенал (магазин)                              │
                                                ├→ Ангар (прокачка)         ◄───────────────────┘
                                                ├→ Бестиарий
                                                └→ Настройки
```

### 4.1 Заставка
Логотип «ПОСЛЕДНИЙ РУБЕЖ», на фоне — трещина бежит по экрану, из неё вылетает дрон. 2 с, пропуск касанием.

### 4.2 Разрешения
Три карточки-шага: «Камера» → «Гироскоп» → «Звук/вибрация». Каждая объясняет зачем. Отказ камеры → «режим без камеры» (тёмная процедурная комната). Отказ гироскопа → управление перетаскиванием пальца.

### 4.3 Главное меню
```
┌──────────────────────────────────────────────┐
│  ПОСЛЕДНИЙ РУБЕЖ            💎 1240  ⚙ Опции │
│                                              │
│   [ ▶ В БОЙ: Сектор 2 «Кухня» ]              │
│   [ Арсенал ] [ Ангар ] [ Бестиарий ]        │
│                                              │
│  фон: живая камера + 3D «Страж» слегка       │
│  покачивается, вдалеке мерцает портал        │
└──────────────────────────────────────────────┘
```
Фон — живая камера (игра сразу ощущается как AR).

### 4.4 Кампания (карта секторов)
5 карточек секторов с замком; под каждой — звёзды (1–3: груз цел / корпус цел / без ремонтов), рекорд волны. Режим «Бесконечная оборона» открывается после 3-го сектора.

### 4.5 Брифинг
Диалог с «Марой» (портрет, 3–5 реплик, пропуск). Список угроз сектора (иконки новых врагов), рекомендация оружия. Выбор лоадаута: зенитка + до 2 слотов доп. оружия.

### 4.6 Подготовка комнаты (2 шага, ~20 с)
1. **«Осмотрись»**: поводи телефоном по полу — ARCore подсвечивает найденные плоскости сеткой; нужна площадь не менее 1×1 м.
2. **«Расставь груз»**: касаниями по найденному полу ставятся 3–5 объектов груза (колонисты/кристаллы), видны голограммой. Можно «Авто».
Игрок фиксируется в точке старта; на запасном режиме (без WebXR) вместо этого — оборот на 360° и указание пола вручную.
Порталы не висят заранее: под каждое вторжение раскрывается фиолетовый портал (сектор 60° перед игроком, 7–12 м, высота 0,4–2,7 м над полом), робот вылезает — портал закрывается. Перед уходом робота открывается красно-оранжевый портал ухода и закрывается за ним.

### 4.7 Бой (HUD)
```
┌──────────────────────────────────────────────────────────┐
│ ВОЛНА 3/8  ░░░░░░▓▓  врагов:12     ❤ КОРПУС ████▒  💎 85 │
│ ◄ портал ●                       ● портал ►  (индикаторы) │
│                                                          │
│                       ⊕ (прицел)                         │
│            👾            👾                               │
│    [груз ▲]      [груз ▲]    [груз ▲]                    │
│  ───────────────── пол ───────────────────              │
│ [ЗЕНИТКА 🔥перегрев ▓▓░]   [🚀 ракеты ×4] [⚡ЭМИ] [🔧]   │
└──────────────────────────────────────────────────────────┘
```
- **Управление:** поворот устройства = прицел. Правая рука: зажать «огонь» (зенитка автоматическая); кнопки доп. оружия — слева/справа снизу. Ракеты: держать на цели 0,6 с — захват, отпустить — пуск.
- **Индикаторы за экраном:** стрелки-«дуги» по краю экрана — где открылся портал и откуда летят угрозы; красная дуга — тем, кто целится в игрока.
- **Полоски:** корпус «Стража», груз (иконки + здоровье «захваченных»), перегрев, боезапас.
- **Вызов Мары:** короткие реплики-подсказки сверху.
- **Волна:** портал раскрывается за 1,8 с (предупреждение) → робот вылезает → портал закрывается; между волнами 8 с на отдых/ремонт/смену оружия.
- **Кража:** враг-похититель подлетает к грузу, «лучом» поднимает его и тащит в открывшийся красный портал ухода. Если сбить до входа — груз падает и невредим. Унесённый груз = минус к звёздам и валюте.

### 4.8 Пауза
Продолжить / Настройки / Выйти (потеря прогресса волны). В паузе камера затемняется.

### 4.9 Итоги боя
Победа/поражение, звёзды, кристаллы 💎 и «ядра» ◈, статистика (точность, убито, спасено груза), «найден новый враг» (бестиарий), кнопки «Дальше», «Ангар», «Повторить».
Поражение: экран полностью трескается и осыпается, «СВЯЗЬ ПОТЕРЯНА».

### 4.10 Арсенал (магазин)
Список оружия (карточки с 3D-превью): зенитка (выдана), ракеты, лазер, молния, ЭМИ, дрон-помощник. Покупка за 💎. Карточка: описание, статы, как использовать, лучший против каких врагов.

### 4.11 Ангар (прокачка)
Вкладки: **Зенитка** · **Оружие** · **Корпус**. Дерево улучшений по 4–5 параметров (урон, скорострельность, охлаждение, радиус, особое). Корпус: броня, ремонтные комплекты, щит от трещин, дальность радара. Покупка за 💎, редкие улучшения требуют ◈ (из боссов).

### 4.12 Бестиарий
Сетка 24+ карточек, силуэт до первой встречи. Карточка: 3D-модель вращается пальцем, класс, слабость, поведение, нанесённый урон, число побед.

### 4.13 Настройки
Чувствительность гироскопа, инверсия, сглаживание, высота телефона, громкость (музыка/эффекты/голос), вибрация, сила трещин (0–100% — доступность), левша (зеркалит кнопки), сброс калибровки, сброс прогресса.

## 7. Повреждения

### 7.1 Повреждения врагов («корабль» ломается)
- У каждого врага 3–6 **частей** (броня, крылья, двигатель, орудие, манипулятор, сенсор), у каждой своё здоровье.
- **Уровни состояния:** 100% — целый; <66% — вмятины, дым; <33% — искры, огонь, потёки; <10% — шатается, теряет управление.
- Отлетающие части — физические «осколки» (инстанс-меши с гравитацией). Потеря двигателя → падает/кружит; потеря орудия → не стреляет; потеря манипулятора → роняет груз.
- Попадание ракеты оставляет «подпалину» (decal), лазера — раскалённую полосу, молнии — разряды по телу.
- Звук: отдельные эффекты по материалу (металл, стекло, пластик).

### 7.2 Повреждения игрока (трещины на стекле)
- Корпус «Стража» = целостность экрана 100%. Каждое попадание по игроку убирает ХП и **добавляет трещину в точке удара**.
- **Процедурная трещина:** от точки удара расходятся 5–9 лучей ломаной с ветвлением, плюс кольцевые «паутинки». Три размера (царапина, паутина, раскол). Трещины накапливаются и остаются до конца боя.
- **Стадии:** 100–67% — отдельные паутинки, лёгкий звон; 66–34% — крупные расколы, блики на сколах, лёгкое искажение рефракции; 33–1% — экран покрыт, кусочки «выпадают» (затемнение сегментов), вибрация, красные предупреждения; 0% — полный разлом, осыпается, поражение.
- Трещины не блокируют игру: максимум 45% покрытия экрана, интерактивные кнопки всегда видны. Ползунок «сила трещин» в настройках.
- **Ремонт:** между волнами — ремкомплект (расходник) стирает трещины с анимацией «нано-восстановления»; в Ангаре — улучшение «самозаживление» (+1% в сек.).
- **Кислота:** вместо трещины — зелёное пятно, разъедающее и скрывающее участок; стирается пальцем/«дворником» (быстрая кнопка).
- Тактильная обратная связь: вибрация (короткая — царапина, длинная — раскол), звон стекла, искры на краях.

## 8. Экономика

- 💎 **Кристаллы**: за убитых, спасённый груз, звёзды. Тратятся на оружие/улучшения.
- ◈ **Ядра**: редкая валюта (боссы, элиты) — для топ-улучшений.
- 🔧 **Ремкомплект**: расходник, 1 включён за волну, остальные покупаются.
- Баланс: сектор 1 даёт ~300💎 — хватает на ракеты и 2–3 улучшения.
- Покупок за деньги нет (MVP).

## 9. Волны

Данные: `{sector, wave, spawns:[{enemy, count, portalId, delayMs}], boss?}`. Сектор = 6–8 волн. Сложность растёт линейно + пики на 4-й и последней (мини-босс/босс). Порталы открываются по очереди; в сложных волнах — 2–3 одновременно. Подсказка Мары: «Портал слева, 3 цели, у одной щит».

## 10. Безопасность и доступность

- Предупреждение «осматривайся вокруг, не ходи с закрытыми глазами»; игра рассчитана на стоячую/сидячую позу, перемещаться по комнате не нужно.
- Нет мигающих вспышек >3 Гц; режим «слабые эффекты» (меньше вспышек и тряски).
- Камера не пишется и не отправляется: всё локально.
- Левша, цветовая индикация дублируется формой, субтитры реплик.

## 11. Риски и открытые вопросы

- Дрейф гироскопа на дешёвых устройствах → кнопка «перекалибровать» в паузе.
- Высота телефона меняется при игре → пол-плоскость уплывает; смягчение: ползунок и автоподстройка по ориентации.
- Нагрев устройства: 30–60 FPS, ограничение числа врагов (≤25), LOD.
- Ассеты: пока процедурные/low-poly (простые меши + шейдеры), позже можно заменить на модели.
